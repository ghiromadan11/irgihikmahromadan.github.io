Website Booking Bukit Bentang Land

Peran Fullstack Web Developer
Teknologi CodeIgniter 4, MySQL, Bootstrap, WhatsApp API
Tahun 2025 / 2026
Kategori Klien Freelance / Pariwisata

Deskripsi Proyek

Proyek ini merupakan platform pemesanan (booking) villa dan cabin berbasis web yang dirancang khusus untuk mempromosikan destinasi wisata serta mempermudah calon pengunjung dalam melakukan reservasi tempat di Bukit Bentang Land. Website ini menyajikan video profil lingkungan cabin yang interaktif, pameran fasilitas, serta integrasi langsung ke sistem komunikasi reservasi.

Fitur Utama

  • Katalog Tipe Cabin & Villa lengkap beserta deskripsi, harga, dan foto fasilitas.
  • Fitur pemutaran video profil dan galeri visual lingkungan Bukit Bentang Land.
  • Formulir booking interaktif yang terintegrasi otomatis dengan WhatsApp Gateway/API.
  • Manajemen event & promosi (seperti acara Yoga, Gathering, dan Event Spesial).
  • Dashboard Admin untuk pengelolaan ketersediaan kamar, reservasi masuk, dan pembaruan konten.

Tanggung Jawab Saya

  • Berkomunikasi dengan klien untuk menganalisis kebutuhan sistem dan alur bisnis reservasi.
  • Merancang struktur basis data MySQL untuk menyimpan tipe cabin, data event, dan pesanan.
  • Mengembangkan logika backend secara penuh menggunakan framework CodeIgniter 4.
  • Mengintegrasikan tautan/API konfirmasi otomatis yang terhubung langsung ke WhatsApp pengelola.
  • Mendesain antarmuka pengguna (UI) yang modern, estetik, dan responsif di berbagai perangkat.

Hasil & Dampak

Dengan hadirnya platform ini, proses pemesanan tempat di Bukit Bentang Land menjadi jauh lebih praktis dan terstruktur. Pengunjung dapat melihat secara visual keindahan lokasi melalui media video/foto serta dapat langsung melakukan booking via WhatsApp hanya dalam beberapa langkah mudah, meningkatkan jangkauan pemasaran dan efisiensi konfirmasi reservasi bagi pengelola.
